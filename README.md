# 📚 Git Cheat Sheet

### Always save file on the vs code with *ctrl+s*  before pushing it on remote repository  

</div>

1. git clone add repository address here : used to clone the repository from git hub to machine. 
2. ls : to list all the visible files
3. ls -Hidden : to view all the hidden files
4. cd : change directory to move from one folder to other in terminal
5. clear : to clear the terminal
6. git status : to check the status of the file
7. git add : to add the file to git staging area *changes the file status from untracked/modified to staged* 
	1. git add . : to add all the new files at once
8. git commit -m"add commit message" : to commit the changes finally
9. git push origin branch name : to change the git repo finally
10. cd .. : to move out of the directory
11. mkdir name : to create a new directory
12. git init : to make the directory a git repo
13. git remote add origin : to add new local repo to remote hub
14. git branch : to check the branch
15. git branch -M name : to rename branch
16. git checkout branch name : to navigate to a branch
17. git checkout -b branch name : to create a new branch
18. git checkout -d branch name : to delete a branch
19. git diff branch name : to compare commits, files.
20. git pull origin branch name : to fetch and download from remote repo.
21. git merge branch name : to merge branches
22. git log : to view commit log and get commit hash

## Undoing Changes

- Staged changes
	1. git reset filename : to reset a specific file
	2. git reset : to reset all changes
- git reset HEAD~1 : to move back one commited change .
- Commited changes(for many commits)
	1. git reset commit hash : to change on git.
	2. git reset --hard commit hash : to change on git as well VSC.
